Java concepts and where they are used

ConceptWhere in the project
Classes and objectsEntities User, Certificate, VerificationLog, Revocation, Institution; role objects AdministratorAccount, IssuerAccount, VerifierAccount
EncapsulationPrivate fields with getters/setters in every entity and in Account; passwords stored only as BCrypt hashes
InheritanceThe three account classes extend Account; InvalidInputException extends BusinessException; CertificateNotFoundException extends ResourceNotFoundException
Polymorphism (overriding)role(), permissions(), dashboardPath(), describe() are overridden per role; DashboardController calls them on an Account without knowing the subclass
Polymorphism (overloading)Account.can(Permission) / can(String); five CertificateService.search(...) variants; verify(id) / verify(id, verifier, ip)
Abstraction and interfacesAbstract class Account; interfaces CertificateOperations and VerificationOperations implemented by CertificateService
CollectionsReportService (List, Set/TreeSet, EnumMap, TreeMap, LinkedHashMap); permission sets as EnumSet
Exception handlingInvalidCertificateIdException, CertificateNotFoundException, InvalidInputException, a global ApiExceptionHandler and friendly 400/403/404/500 pages
